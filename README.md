# حقيبة Arduino للمبتدئين

موقع تعليمي عربي تفاعلي: شرح لوحة Arduino Uno، المكونات بصور حقيقية، 13 درسًا ومشروعًا مع مخططات توصيل، محاكيات، اختبار، أوراق عمل قابلة للتحميل، ودليل المدرب.

## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد إلى مستودع جديد (index.html في الجذر).
2. من Settings ثم Pages اختر الفرع `main` والمجلد `/ (root)` ثم Save.
3. بعد دقيقة يصبح الموقع متاحًا على `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`.

الموقع ملف واحد مستقل (الصور وأوراق العمل مضمّنة داخله)، ونسخ PDF من أوراق العمل موجودة أيضًا في مجلد `worksheets`.
